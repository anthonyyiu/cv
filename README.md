# Anthony Yiu Portfolio

A personal Interactive Arts & Technology portfolio inspired by editorial case-study layouts. It is built with plain HTML, CSS, and JavaScript so it can be customized without a build step.

## Run locally

Open `index.html` in a browser, or use VS Code's Live Server extension. The project cards open local case studies: `project1.html` through `project4.html`.

## Customize

- Replace the name, email, project titles, and descriptions in `index.html` and the project pages.
- Adjust colors and typography in the `:root` section of `styles.css`.
- Replace the Framer-hosted image URLs with local images when ready.
